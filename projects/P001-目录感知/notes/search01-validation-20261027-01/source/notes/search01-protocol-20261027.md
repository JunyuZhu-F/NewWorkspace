# SEARCH-01 小数据检索准入协议 v1

2026-10-27。用户指定先做 SEARCH-01，在小数据上打通并验证检索链路。本协议在新检索运行前固定；后续变更另存版本，不回改旧 DIR-01/COST 协议或结果。

## 依据、选择及边界

- 论文 PDF p.9 §V-A：三目录方案共用 PG/IVF，ARXIV 约束内 brute-force 真值、Recall@100 和端到端延迟。当地固定 PDF 提取证据为 `reading-20261026/source_bundle.json` 第9页；数据仓库固定 README 说明1024D向量和约束。原文未恢复距离、归一化和具体 Viking 参数。
- 旧 `data-audit.md` §8 的20查询真值顺序仅支持 L2 相容性推测。本轮**项目协议**选择原始 float32、不归一化、平方欧氏距离，double逐维累计，距离相等按原始ID升序。不是作者距离设置已经证实。
- 本轮后端：新增独立 C++17 exact 和 IVF-Flat（非 Viking、非作者 IVF），三目录实现用同一只读向量矩阵、同一个训练好的后端对象。未接 PG；本轮只验收 IVF 小规模分支，不关闭原版引擎/PG或完整 OBJ-04。
- 不安装依赖、不训练 embedding、不加载全量向量、不做 SEARCH-02 正式性能曲线。本轮 IVF 训练只是10k后端的8次小规模分区迭代。

## 输入和选样（不看 GT 或检索结果）

- corpus 固定旧时间样本前10000行，ID=0..9999；重用 `time-pilot-20261026-01/bindings.jsonl`，检查其冻结hash。只读相应10000个1024D fvecs完整记录（41,000,000字节），每条核对维度/有限值。向量行对应ID是项目明确采用的行号映射，未证明embedding内容语义与每篇论文一致。
- 混合约束必须完整按query_id=0..999排序。按time路径深度1和2，各取query_id升序前8条，分别执行递归/非递归。完整读查询fvecs（4,100,000字节），核对全部1000条维度/有限值，选用上述ID及ID0。
- 为避免旧10k主要位于早年、原始查询大量为空而形成空集假通过，额外使用query_id=0的真实向量，查询旧样本全部34个目录及显式空目录`/__empty__/`和不存在目录`/__missing__/`，各两种模式。这些约束是项目诊断，单独标记，绝不冒充作者工作负载。
- k=100；预计104条case（32原始约束模式展开、72诊断），每条均保存原始query_id、路径、模式、来源。预先固定所有case，不依赖答案挑选。
- 不读取或筛选发布的全库GT来生成子集GT。独立 Python/NumPy 在当前10000条内逐项过滤、穷举平方L2、按(distance,ID)排序，重新生成精确top-min(k,scope_size)。

## IVF 固定参数及过滤

- nlist=16，种子42，C++标准mt19937；依次取 `engine()%10000`、重复重取，初始化16个不同原始行。
- 全10000条参与粗量化训练，不用query或GT训练/选参；Lloyd固定8次，无提前停止；double中心/累加、行号顺序，中心并列取小中心号；空簇保留前次中心。8次更新后重新分配到最终中心。
- 保存最终中心、所有行的分区号。nprobe固定1、4、16，另exact以probes=0编码。中心按(平方L2,中心号)探测；只对**目录允许集合与选中分区的交集**评分，再取top-k；不以全库top-k后过滤代替。
- nprobe=16必须与独立精确真值完全同ID顺序；nprobe=1/4不设召回通过阈值，保留低召回/不足k，不补搜。Python独立重算最终分区最近中心、探测中心及候选内top-k。

## 指标及完成条件

- Recall@100=返回ID与当前子集精确GT交集大小/GT大小，GT大小=min(100,允许条目数)。空GT记null，报告空/非空case数量；宏平均只含非空case，原始约束与诊断分开；没有“至少命中1条”替代召回。
- 重复ID、越界ID、范围外ID均失败。少于k按实际长度；同分用ID确定排序。k=0、重复向量、并列、路径段边界、空/缺失目录和MOVE/MERGE后向量ID稳定由合成契约测试覆盖。
- 本分支不计算WIKI nDCG：其qrels增益、IDCG及原始约束仍未恢复。不能以ARXIV的距离top-k充当WIKI相关性分级真值；该项明确不适用，不虚构规则。
- Release/ASan契约测试通过；两种构建均运行同一104-case输入；3目录方案候选集合与独立路径判定逐项一致，4个配置的结果与独立实现一致，精确/全探测每个非空case召回1；两构建结果相同。
- 保存命令、环境、源码/二进制/输入/输出hash和原始结果；现有30文件COST快照内容不变。无延迟通过阈值，不把验证进程运行耗时当作论文查询延迟。

完成后进入SEARCH-02的IVF分支设计/运行。原版数值不可比、PG、WIKI和真实类别协议缺口保留；SCALE-01在小规模检索验证后另行评估。
