# ARXIV 类别字段：已查明的边界与不能推断的内容

日期：2026-10-26。对应 DATA-01 → SPEC-01。本轮只分析既有目标元数据和公开来源，没有改写原数据、读取向量或实现三种目录索引。

## 1. 本轮结论

**现有材料不能唯一确定 categories 的直接绑定含义。** 这不是增加同类递归查询抽查就能解决的问题：把冗余祖先路径视为辅助信息，或者把它也视为直接归属，可以产生完全相同的递归范围，但产生不同的非递归结果。

本轮的类别解释调查已完成；作者原始类别非递归/多归属 DSM 协议仍未恢复。不能为了将 SPEC-01 标为完成而任选一种解释。

## 3. 用已有数据检验：递归结果无法区分两种解释

为避免重复扫描大型 metadata，本轮复用上次保存的 1,998 条原始目标记录，在内存中比较两个假设视图：

- **视图 A**：所有列出的路径均保留。
- **视图 B**：若某路径是同一条目另一条路径的严格祖先，仅在这个假设视图中省去它；其余路径全部保留。原始 categories 列表不改写，也不把 B 采纳为正式数据预处理。

| 检查 | 实际结果 |
|---|---:|
| 不同目标条目 | 1,998 |
| 含冗余祖先路径的条目 | 1,035 |
| 在假设 B 中省去的祖先标签总数 | 1,223 |
| A/B 的全部前缀锚点集合相同的条目 | 1,998 |
| 即使省去祖先标签，仍有多个不可互相包含路径的条目 | 1,014 |
| 合成小路径域的独立前缀成员检查 | 567 次，全部一致 |

这些条目来自上次选中的 GT，不是全库随机样本，数字不能作为总体比例。

### 为什么这种一致不是偶然

设 P 是一条记录的所有列表路径，L 是其中不再有更深后代的路径。递归范围规则为：锚点 q 是某个归属路径的前缀时，条目可进入 q 的范围。

如果省去的 p 是某个保留路径 l 的祖先，那么 q 只要是 p 的祖先，也一定是 l 的祖先。因此省去 p 不会消除任何递归范围匹配；保留路径又是原列表的子集，不会新增匹配。

所以，对这种前缀成员规则，P 与 L 的递归观测一致。这个论证适用于任意有限路径集合；1,998 条记录和 567 次检查是对诊断实现的验证，不是仅靠统计相似作结论。

### 非递归却可能不同

以 id=40238 为例，原列表为：

```text
/Physics/nlin/
/Physics/nlin/nlin.CD/
```

若两条都定义直接绑定，非递归查 `/Physics/nlin/` 应包含该 ID；若第一条只是第二条的祖先信息，则该非递归查询不应包含它。两种解释在所有递归查询上仍一致。

因此，上一轮的“2,000 个 GT 都递归匹配”不能判别哪一种才是作者的 Local。直接使用 `Inc(parent) - union(Inc(children))` 会隐含选择一种直接归属解释；必须先有语义依据，不能把数学式的计算结果反过来当作数据生成方式的证据。

## 4. 去掉祖先标签也不能消除真实多分支问题

视图 B 仍有 1,014 条记录保留两个或更多互不包含的路径。实际保留路径数的分布是：1 条有 984 个条目，2 条有 560 个，3 条有 273 个，4 条有 127 个，5 条有 48 个，6 条有 5 个，8 条有 1 个。

因此，不能认为“只保留最深路径”会自然恢复一条记录一个目录。这里也没有选择任一最深分支来丢弃其他分支。

条件性逻辑例子，使用已保存的真实 id=249848：它同时位于 gr-qc、astro-ph、hep-ph、hep-th 等 Physics 分支。假设每个列表路径都是独立绑定，把 gr-qc 绑定移到 Mathematics 后，它仍通过其他分支属于 Physics。若对 Physics 直接减去包含这个 payload ID 的源集合，就会误删它的剩余归属。

这是说明某种多绑定解释需要额外一致性定义的逻辑反例，**没有运行论文维护实现，也不构成作者代码存在 Bug 的证据**。本项目没有为解决此问题暗加引用计数、复制向量或重定义 payload ID。

## 5. 采用的执行边界

1. **忠实核心**：仍按论文单父目录模型制定三方案语义，人工树约定见 `operation-spec.md`。不将多类别改造覆盖原基线。
2. **类别递归材料核查**：保留全部原始路径，已完成的成员核查继续有效；不因此推定 Local 或 DSM。
3. **真实类别非递归与多归属 DSM**：明确为材料/协议阻塞。解除需要作者生成规则、catalog/归属映射或等效可靠证据；不能靠更多同类递归真值唯一还原。
4. **可推进的主线子范围**：先准备与相关性真值无关的 ARXIV 时间命名空间小样本。建议固定 corpus 前 10,000 个 ID/行，保存原始 time 到目录视图的映射，核对单路径、ID、目录统计和输入清单；暂不读取向量或跑索引。这是本项目诊断输入，不冒充论文原始 query/DSM 分布。
5. **范围保护**：不取消类别部分或 WIKI 的最终核查目标；父任务 DATA-01/SPEC-01 仍未整体完成。阶段拆分不是宣布问题已解决，也不是启动正式实现。

选择时间字段作为一个独立单命名空间输入，是为了推进与论文单父目录模型一致的小样本检查；它不表示原文一定以同样方式物理隔离了两个命名空间。
