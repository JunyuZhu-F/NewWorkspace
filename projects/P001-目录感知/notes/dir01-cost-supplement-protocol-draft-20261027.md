## 3. 独立构建与阶段定义

新增诊断构建，默认 directory_core 路径、字段布局与默认二进制构建选项不变。phase_diag 与 allocation_diag 各自单独编译，均使用现有 MSVC Release/CRoaring，不改第三方源码。不得把分配追踪和纳秒计时同时开启。

拟定阶段：

| 操作 | 直接观测的互斥阶段 |
|---|---|
| DSQ | 参数解析/目录定位；返回 bitmap 创建/复制；子目录枚举与并/差；显式临时对象清理 |
| DSM | 参数/合法性/定位；目录重映射或重挂/冲突协调（不含 catalog）；独有祖先 bitmap 更新；catalog 访问/扫描/重绑定；清理及异常处理 |
| build | index/根构造；目录定位/创建；catalog contains/bind；posting/Inc 写入；临时对象清理 |

嵌套函数必须拆成直接计时的互斥区间，catalog 起止时暂停目录区间，返回时开启新的目录区间。每条 raw 记录保存各区间直接差值、调用数及阶段标签；不能把 `public_total - catalog_total` 命名为目录净时间，不能把计数乘常数当时间。目录净阶段合计仅为已直接观测目录区间之和，保留阶段覆盖状态；若漏掉清理/异常区间，标 incomplete，不宣称完整目录净成本。

公开 total 外层独立采集；各阶段和 total 不要求严格相等（探针、区间边界有成本），不得用“剩余时间”补造阶段。未分类部分标 not_collected，不从总量减出数字充当测量。拒绝操作单列，catalog 未调用标 no_call/0；不使用之前操作的计数。

计时记录不在区间内进行 I/O、分配日志容器或做 oracle。固定容量栈记录活动区间，每个闭合区间立即向固定阶段的累计时长/调用数归并；每个公开操作保存一行各阶段累计值，build 按原构建迭代保存累计值，不为 10,000 次 insert 输出海量逐 span 日志。原始逐查询/逐 DSM/逐构建样本仍完整保留，不跨样本先汇总。若保存额外事件明细，必须预留容量、溢出失败，不静默截断。异常展开通过局部 RAII 关闭事件。该实现尚待审查，若必须改变算法执行顺序才可实现，则停止并重设计。

每进程保存空计时区间和 phase begin/end 空框架的 10,000 次开销分布，不从实测中扣除。记录 Clock::period 为 nominal_period_ns，另保存实测最小非零 delta、零 delta 比例；不可将标称 1 ns 周期当实测分辨率。极短阶段在开销同量级时标“不可可靠分辨”，仍保留原值，不据此排序。

## 4. 内存归属与实现可行性

**目标口径是 requested live allocation bytes，包含实际请求容量，不包括分配器内部元数据、碎片或 OS 提交量。** 不称为完整物理堆。进程 working set/private/peak、portable bytes 继续分列。不能只用 sizeof、条目数乘估值或进程前后差来伪造完整容量。

拟在诊断可执行文件内追踪 C++ 分配/释放和 CRoaring 的官方 memory hook。本地 v5.3.2 的 roaring.h:9968–9985 提供 malloc/realloc/calloc/free/aligned_malloc/aligned_free，接口存在已核查；钩子兼容性、完整覆盖、透明性尚未验证。不得修改上游文件或把启用 hooks 后的数据当默认耗时。

| 所有权类别 | 包含 |
|---|---|
| directory_structure | 索引对象（排除 catalog 嵌入部分）、目录节点、PE 路径键/children 辅助索引、Trie segment/child map、容器节点与 buckets、字符串动态缓冲 |
| catalog | catalog 嵌入控制对象及 ID→目录句柄 map 的全部动态分配 |
| bitmap_storage | CRoaring 实际分配的根结构/容器/动态容量；Bitmap 内嵌指针按所属目录对象只计一次 |
| temporary / observer | 操作临时空间及追踪器本身独立记账；oracle、输入、输出、校验不算索引持久对象 |

一个分配只能属于一个所有者。根索引分配块若嵌入 catalog 控制对象，按实际子对象范围拆归属，大小总和必须等于原请求块，不能再次叠加 sizeof。SSO 留在对象块内，不重复计容量；外部分配按实际请求记录，map 节点/哈希桶不能漏记。bitmap 外部块不能再加 portable 大小。当前释放的临时空间在稳定态 live bytes 中应为 0，操作峰值另列。

必须区分“稳定拥有者”和“当前执行阶段”：目录重挂后归属随对象身份保留；临时位图后来转为持久对象时须转移标签。释放/realloc 无论当前标签为何都按原指针账本核销；realloc 失败保留旧块，calloc 溢出、aligned new/delete、sized delete、空指针、抛出 new、aligned hook 都须验证。账本自身分配使用防重入的独立通道，不计入索引；不改变原分配器策略或容器类型。

记录 initial/after_move/after_merge/after_rejection/after_destroy 等状态的分类 live bytes、持久字节、操作峰值、未归属块/字节和 API 覆盖状态；总计为互斥类别之和。oracle 在采样时不得存活；检查函数临时数据应离开作用域后才继续采样。allocator 保留缓存仍可能影响进程值，不能因此把进程总量当索引净值。

目录/catalog/bitmap 稳定存活分配在 index 销毁后必须归零；拒绝操作前后语义与持久账本应不变。若有未归属存活块、遗漏 API 或不能识别转移，记 incomplete，保留已有分项但不得关闭完整逻辑内存缺口。先做小规模可行性门，不能未经核验就承诺“完整”。
