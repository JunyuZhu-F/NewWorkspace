# 实验索引与记录模板

> 填写说明：这里只登记真实计划或实际运行；所有 `<待填写：…>` 都是占位说明。未知内容写“待确认：…；验证方式：…”，不适用项说明原因。论文报告值与本项目实测值必须分别标注。未运行、失败或中断时不得填写虚构结果。

## 1. 记录约定

- 实验编号建议为 `EXP-<YYYYMMDD>-<三位序号>`，项目内唯一；每个独立运行使用唯一运行编号。多个种子可归入同一组实验，但逐次记录种子、命令、输出及状态。
- 推荐在 `experiments/<实验编号>/record.md` 保存完整记录，本文件保留索引；也可把下方模板直接复制到本文件并使用唯一标题。选择一种方式，索引指向唯一的正式记录，避免维护两份正文。
- 启动前登记目的、协议、代码、数据和命令；结束或中断后补充真实状态、结果、日志及分析。重跑保留旧记录和输出，使用新的运行编号或实验编号。
- 保存实际使用的配置快照及命令行覆盖项，不能只引用可能继续变化的配置文件。代码存在未提交修改时保存差异和必要的未跟踪源文件快照；没有 Git 时保存代码快照和校验清单。
- 大型日志、权重和数据只记录定位路径与必要校验信息；不在本文件粘贴完整日志。
