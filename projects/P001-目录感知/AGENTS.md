# 项目操作约定

本文件只记录本论文项目的特有约束；工作区根目录 `AGENTS.md` 的科研诚信、证据、安全、Git 和资源规则继续适用。

## 1. 项目特有约束
- 采用论文 arXiv:2606.16903v1；材料版本、哈希和关联源码边界以 `notes/materials-and-gaps.md` 为准，详细方法见 `notes/paper-card.md`。
- 用户已确认目录层复现范围、暂不做应用实验、先用现有电脑小规模检查；用户已进一步授权单父目录核心正式实现与审查，按 ENV → ORACLE → CORE 推进；真实数据缺口保留，正确性验证先于性能，大规模运行另行批准。
- 保留 PE-ONLINE、PE-OFFLINE、TrieHI 的论文操作差异；不可用额外直接归属缓存等优化覆盖忠实基线。目录集合正确性验证先于性能测量。
- 数据在本项目 `dataset/raw/`，原文件只读；缺失的 WIKI 目录约束或 DSM 序列不得用未声明的自建协议冒充。平台先用现有电脑，其他技术选项按计划核验。
- 2026-10-27用户已授权WIKI独立小规模协议及执行/审查，不再等待作者联系；原始协议缺口继续保留。查询目录/配对与维护序列须在运行前冻结且独立于qrels；本分支仅报告子集精确GT的Recall@10，nDCG因标注覆盖不足暂不报告。真实命令、准入、默认与诊断分池、失败和源快照必须保留。

## 2. 文档职责与读取策略

| 文件 | 职责 |
|---|---|
| `TASK.md` | 复现目标、范围、约束与验收标准 |
| `REPRODUCTION_PLAN.md` | 本论文的执行路线、依赖、任务状态与完成条件 |
| `STATE.md` | 当前真实状态、阻塞、最近验证和下一步 |
| `EXPERIMENTS.md` | 实验索引与记录规范 |
| `experiments/` | 每次实验的配置、运行事实、结果和证据 |
| `README.md` | 项目介绍、环境、运行入口和导航 |

新会话默认先读取适用的根/项目 `AGENTS.md`、`STATE.md`、`TASK.md`。根据任务按需读取 `REPRODUCTION_PLAN.md`、论文、代码、测试、实验记录及 `notes/`，禁止仅为了解项目而递归读取全部历史文件。

## 3. 论文理解与方法落实
- 记录论文及补充材料的版本、来源和本地路径。
- 将论文原文、官方实现、自行推断和实验性修改区分开。
- 重要公式、算法步骤和实验协议应保留原文定位；不确定项写明验证方法。
- 在实现前确认输入输出、关键不变量、数据划分和评价协议。

## 4. 实现、测试与记录
- 修改前检查代码位置、当前差异、依赖和调用关系。
- 以 `TASK.md` 的范围与验收标准为约束；阶段安排和任务依赖以 `REPRODUCTION_PLAN.md` 为准。
- 运行测试或实验后，保存真实命令、配置、代码版本、状态、结果与证据路径。
- 验证失败、运行中断或未执行均如实记录；不得仅凭计划或文件存在就将任务标记为完成。
- 交接时更新 `STATE.md`，并只更新发生变化的计划和实验记录。
