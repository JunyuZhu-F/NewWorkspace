# SEARCH-02 small-data experiment

Run from the project root with the existing Anaconda Python/NumPy/psutil and
MSVC/CMake/Ninja tools. No packages or corpus vectors are downloaded. Frozen
choices: `../../notes/search02-protocol-20261027.md`.

```powershell
python code/search02/pipeline.py --stage prepare --preparation notes/search02-new-preparation
# After successful admission, register a new experiment ID in EXPERIMENTS.md.
python code/search02/pipeline.py --stage run --preparation notes/search02-new-preparation --experiment EXP-NEW-ID
```

Existing evidence directories are never replaced. The current successful admission
is `notes/search02-preparation-20261027-02`, which reuses the valid input from
`notes/search02-preparation-20261027-01/fixture`. The first attempt preserves a
generated-include CRLF guard failure. CMake now forces UNIX newlines, so the
generated library prefix matches SEARCH-01 bytes exactly. Neither the original
backend nor the directory core is edited.

The sample is 10,000 globally spaced IDs, not the old corpus prefix. Explicit
global/dense ID mapping is checked and timed. All 501 real time queries are
expanded into recursive/nonrecursive project modes; empty year-local scopes remain
in latency summaries and are excluded from Recall denominators. Approximate
parameters are fixed, not tuned on these queries. The shared independent IVF
prototype still scans allowed IDs and checks their partition; it is not Viking or
an optimized posting-list implementation.

The runner starts five sequential Release workers and preserves each query timing,
baseline ranking, candidate set, model, order, calibration, setup cost, sampled
resource telemetry, command, environment and failure. Independent verification
checks 1,202,400 formal timing rows plus all baseline ranks. Models and ranks must
match across strategies, runs, and admission builds. Old snapshots are checked.

Postprocessing uses `analyze.py` only after verification. The base Anaconda
Matplotlib 3.5.2 cannot import with NumPy 2.0.2 on this machine. An existing Python
3.10 environment with NumPy 1.26.4 / Matplotlib 3.10.9 was used with its own DLL
directories first in the **child** PATH, without modifying environments. The exact
successful launcher is preserved in the preparation evidence, and the experiment
records its command and versions in `plot-runtime.json`. Final curves are under
`experiments/EXP-20261027-006/analysis-02/figures`; earlier failed rendering logs and
partial source-data exports are retained separately. PDF font/collision audits and
single-axis alignment-not-applicable records accompany the final exports.

`results.md` and the curve CSV describe this independent time/sample protocol.
They do not close PG, WIKI, category ownership, full-scale, or original-Viking
reproduction tasks. No performance results are generated by admission tests alone.
