## 1. 复现口径与证据

采用 *Directory-Aware Query and Maintenance in Vector Databases*，arXiv:2606.16903v1。§III/IV为目录操作依据；PDF p.9 §V-A定义目录候选集合解析、DSQ质量/总延迟、DSM及资源指标，并明确其部分成本比较排除公共catalog。PDF p.10 Table IV支持递归/非递归的不同取舍，Figure 9对应作者DSM序列。我们的默认维护API计时包含catalog，因此不能直接对齐其排除后的数值。

原三方案核心为本项目独立实现，不是作者实验源码。Roaring及环境固定，但本机Windows与论文Linux/125GB服务器、容器细节和向量后端不同。范围查询不借公共catalog或额外Local缓存走捷径；catalog指针归属及容器是项目工程落实，不声明恢复作者全部实现细节。正确性来源为独立枚举判定、人工锚点、随机混合序列和Release/ASan，不是三方案互相一致就认定正确。

WIKI **语料层级已有**：`corpus_paths.json`提供条目路径。缺的是`query.jsonl`里逐query的目录范围，456条metadata为空；README虽指定该文件含约束，实际内容与说明不符。用户另下载网盘也确认空metadata，并决定不等待作者联系。现行做法是“真实数据、真实层级＋本项目生成查询和维护工作负载”，不是重新生成整棵目录树，也不是恢复作者约束。

本轮自审与证据复核：[核验JSON](notes/report01-audit-20261027-01/run-02/verification.json)、[审计脚本](notes/report01-audit-20261027-01/audit.py)。核对006–008的110个worker文件、153个源码清单项的当前/归档副本（含跨实验重复项）；005已存raw/hash清单匹配；直接重算004所引用time/default均值与005 MERGE catalog比例。没有重新调用任何实验运行器。旧001–003及准备/导出失败保持原样。

## 4. 检索结果怎样解释

以预先固定的nprobe4为一个展示点，所有参数点仍保留在[006](experiments/EXP-20261027-006/results.md)与[008](experiments/EXP-20261027-008/results.md)。下表是非空case均值；不是新增挑选/调参。

|---|---:|---:|---:|---|
| ARXIV递归 | 100 | 501/0 | 0.555440 | 121.2350 / 107.1855 / 107.7700 |
| ARXIV非递归 | 100 | 235/266 | 0.363283 | 29.1679 / 28.1565 / 28.1088 |

三方案在各点质量相同，exact/全探测非空Recall均为1，是链路一致性的证据，不是高质量应用效果的证明。partial-probe低召回保留；未为追求论文数值调参或删case。后端是遍历允许ID并过滤分区的独立IVF原型，不能推成优化倒排或Viking的性能。

**空范围改变报告对象，也可能改变排序。** ARXIV非递归nprobe4若计全部501请求，均值为19.3488 / 23.2547 / 22.5033μs，ONLINE最低；仅非空235请求时则OFFLINE/TrieHI略低。WIKI非递归全部456请求均值为15.0660 / 50.2140 / 43.2245μs；只报127非空请求会遗漏329空范围的成本。空GT质量为null，不填1或0冒充有真值的评分。[全部汇总及阶段CSV](notes/report01-audit-20261027-01/run-02/retrieval-probe4-comparison.csv)保留两种口径。

五个进程的描述性配对方向：两个数据集递归nprobe4中OFFLINE/TrieHI均为5/5低于ONLINE；ARXIV非递归仅3/5低于ONLINE，WIKI非递归仅1/5低于ONLINE。小幅总量差不能宣称稳定或显著，[配对符号与范围](notes/report01-audit-20261027-01/run-02/paired-signs.csv)不替代显著性检验。

ARXIV非递归目录阶段仍是ONLINE较低（1.1185 / 1.5078 / 1.2198μs），总量非空均值排序却不同；ID转换和后端阶段有缓存/执行波动，不应把总量差全部归因目录。WIKI也需按阶段解释。加载、训练/聚类构建、建树、输出/传输与最后临时集合释放不在查询总量内，不称完整服务延迟。

WIKI配对规则独立于query文本主题与qrels，因此Recall@10回答“这个项目目录范围内，近似搜索能找回多少精确近邻”，不回答“query是否得到符合用户意图的目录和相关文档”。nDCG未执行；样本仅46个query有相关性标注，不能将另外410个query的未标注当不相关，也不能把它们与329个非递归空范围混为同一件事。若以后要自然任务相关性，需要另定query范围、标注覆盖与评价协议；不是给现有表补一列，也不以联系作者作为当前分支前置。
